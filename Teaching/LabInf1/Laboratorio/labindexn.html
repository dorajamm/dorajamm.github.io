    5. Congettura di Collatz ver.1
      La congettura di Collatz è una delle più semplici congetture matematiche non ancora risolte. La congettura riguarda il seguente algoritmo:
      Si prenda un intero positivo n. 
       1.Se n = 1, l'algoritmo termina.
       2.Se n è pari, si divida per due; altrimenti si moltiplichi per 3 e si aggiunga 1.
       3.Si ripete l'algoritmo da 1. sul numero ottenuto.
      Per esempio, iniziando con n = 6, otteniamo la successione 6, 3, 10, 5, 16, 8, 4, 2, 1.
      La congettura di Collatz asserisce che questo algoritmo giunge sempre a termine, indipendentemente dal valore di partenza.
      Scrivere una funzione int Collatz( int x) che prende in input un numero intero x (restituisce void) e stampa sullo schermo la sequenza di Collatz da x a 1.(La stampa in questo caso è fatta all'interno della funzione).     2. Un gioco enigmistico: il lucchetto
      Nel linguaggio enigmistico un lucchetto è un gioco caratterizzato dallo schema XY + YZ -> XZ. In pratica si trovano due parole w1 e w2 in cui l'ultima parte (un suffisso) di w1 è uguale alla prima parte (un prefisso) di w2.  VELA/LANA = VENA; 

 CRISTALLO/STALLONE = CRINE;

 RISCHIO/SCHIOCCO = RICCO,

 MAGGIO/GIOIA = MAGIA

 CARATO/ATOMI = CARMI

 CAST/TERME = CASERME

 MATCH/CHADOR = MATADOR.
